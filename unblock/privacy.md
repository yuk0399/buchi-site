このページでは、iOS アプリ「ブチねこ、ぬけだす」が扱うデータについて説明します。このアプリは、個人の開発者 Yutaka Kawakami が提供しています。

## アカウントと保存するデータ

- このアプリには、アカウントもログインもありません。
- 名前、メールアドレス、電話番号、位置情報 (GPS) を求めることはありません。
- 進み具合 (星、記録、設定) は、端末の中だけに保存します。開発者のサーバーには送りません。開発者はサーバーを持っていません。
- アプリを削除すると、端末の中の記録は消えます。

## 問い合わせのメール

メールで問い合わせをいただいたときは、メールアドレスと本文を、返事のためだけに使います。

## 広告 (Google AdMob)

無料版では、Google AdMob の広告 (リワード広告とインタースティシャル広告) を表示します。広告なし版を購入すると、広告は表示しません。

Google は、広告の配信と計測のために、次のような情報を集めます。

- 端末の識別子
- IP アドレス
- おおまかな位置 (IP アドレスから推定したもの)
- 広告の表示やタップの記録

アプリは、iOS の「トラッキングの許可」(App Tracking Transparency) を求めます。許可しなくても、遊び方は変わりません。許可しない場合、広告の識別子 (IDFA) は使われません。

英国などの対象地域では、最初に広告が必要になったときに、Google の同意の画面を表示します。同意しないことも選べます。あとから、アプリの「設定 > 広告のプライバシー設定」で変えられます。この項目は、対象地域でだけ表示されます。

広告の内容は、Google の区分で T (ティーン) までに絞っています。

- [Google のプライバシーポリシー](https://policies.google.com/privacy)
- [Google がパートナーのアプリから得た情報をどう使うか](https://policies.google.com/technologies/partner-sites)

## 利用状況の計測 (Google Firebase Analytics)

難易度の調整とアプリの改善のために、遊んだ記録を集めます。例えば、次のような記録です。

- ステージを始めた、クリアした、途中でやめた
- 手数、クリアまでの秒数
- ヒントを使った
- 広告が表示された、購入した
- 毎日1問を解いた、結果を共有した

あわせて、Firebase が自動で集める情報があります。

- アプリのインスタンス ID (アプリごとの識別子)
- 端末の機種、OS のバージョン
- おおまかな国や地域
- アプリを開いた回数や時間

広告の識別子 (IDFA) は集めません。このデータを、広告の個人化には使いません。

- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)

## クラッシュの報告 (Firebase Crashlytics)

アプリが落ちたときに、原因を調べるための記録を送ります。

- クラッシュの内容
- 端末の機種、OS のバージョン、アプリのバージョン
- Crashlytics のインストール ID

- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)

## 購入 (Apple と RevenueCat)

支払いは、Apple が App Store で行います。開発者は、カード番号などの支払いの情報を受け取りません。

購入の確認と復元に、RevenueCat を使います。RevenueCat が扱うのは、アプリが作る匿名の ID と、購入の記録 (商品、日時、取引の ID) です。名前やメールアドレスは渡しません。

アプリを削除して入れ直すと、匿名の ID は新しくなります。アプリの「設定 > 購入を復元」で、広告なし版に戻せます。

- [RevenueCat のプライバシーポリシー](https://www.revenuecat.com/privacy)

## 結果の共有

結果の共有は、ボタンを押したときに iOS の共有の画面を開くだけです。開発者には何も送られません。

## データの使い方と保存する場所

- データを売ることはありません。
- 集めたデータは、このページに書いた目的のほかには使いません。
- データは、各社 (Google、RevenueCat) のサーバーに保存されます。日本の外 (米国など) で扱われることがあります。

## 子どもの利用

このアプリは、大人向けに作りました。13歳未満の子ども向けには作っていません。

13歳未満の子どもの情報を、それと知って集めることはありません。

保護者の方で、子どもの情報が送られていると気づいたときは、[buchi.support@gmail.com](mailto:buchi.support@gmail.com) に連絡してください。

## データの削除と問い合わせ

計測とクラッシュの記録は、匿名の ID でまとめられています。開発者は、これを特定の人と結び付けられません。

データを消したいときや、質問があるときは、下のメールアドレスに連絡してください。アプリを削除すると、端末の中の ID も消えます。
